# Кабинет техспеца

Технический кабинет обслуживания LivingBraiding: состояние данных, SQL-доступ только для диагностики, медиа-бэкапы. Это не рабочий кабинет мастера или админа студии.

Кнопка **?** появляется на экранах, для которых заполнена страничная справка.

## Что умеет кабинет

- Смотреть технические сводки и таблицы на главной / в разделе данных
- Выполнять **только чтение** через SQL-консоль (если доступна на экране)
- Скачивать и восстанавливать медиа-бэкапы (фото и загрузки)
- При необходимости помогать с правками в закрытых периодах по регламенту продукта (с подтверждением на экране)

## Основные разделы

- [Главная](/) — сводка и медиа-бэкап
- [Технические данные](/techspec/data)
- [SQL](/techspec/sql)

## Частые сценарии

1. Проверить объём медиа / сделать бэкап → блоки на главной.
2. Найти «пропавшую» запись → технические данные или SQL (только SELECT-сценарии, которые допускает экран).
3. Восстановить фото из zip → форма восстановления медиа.

## Важные ограничения

- Нет обычного меню студии (клиенты, склад, отчёты) в этом кабинете — переключите роль, если она назначена.
- SQL и purge-подобные действия — зона риска: не выполняйте ничего, чего нет в регламенте.
- Тексты справки для сотрудников правятся в файлах репозитория и выходят с деплоем (отдельного редактора в MVP нет).
