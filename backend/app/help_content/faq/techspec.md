# Кабинет техспеца

Технический кабинет обслуживания LivingBraiding: состояние данных, SQL-доступ для диагностики и точечных UPDATE, медиа-бэкапы. Это не рабочий кабинет мастера или админа студии.

Кнопка **?** появляется на экранах, для которых заполнена страничная справка.

## Что умеет кабинет

- Смотреть технические сводки и таблицы на главной / в разделе данных
- Выполнять **чтение** через SQL (`SELECT` / `WITH` / `EXPLAIN`) и точечный **`UPDATE` с обязательным `WHERE`**
- Скачивать и восстанавливать медиа-бэкапы (фото, видео и остальные загрузки с диска, в том числе без ссылки в базе)
- Удалять файлы без ссылок в базе кнопкой «Удалить лишние» (файлы моложе часа не трогает)
- При необходимости помогать с правками в закрытых периодах по регламенту продукта (с подтверждением на экране)

## Частые сценарии

1. Проверить объём медиа / сделать бэкап / убрать файлы без ссылок → блоки на главной. Замена фото или удаление записи сама убирает файл, если он больше нигде не указан.
2. Найти «пропавшую» запись → технические данные или SQL (SELECT).
3. Точечно поправить строку → `UPDATE … WHERE …` с галочкой подтверждения на экране SQL.
4. Восстановить фото из zip → форма восстановления медиа.
5. Уведомление мастеру не ушло → «Очередь уведомлений», статус и повтор.

## Важные ограничения

- Нет обычного меню студии (клиенты, склад, отчёты) в этом кабинете — переключите роль, если она назначена.
- `INSERT` / `DELETE` / DDL и `UPDATE` без `WHERE` запрещены.
- SQL и purge-подобные действия — зона риска: не выполняйте ничего, чего нет в регламенте.
- Тексты справки для сотрудников правятся в файлах репозитория и выходят с деплоем (отдельного редактора в MVP нет).
- Доставка Max на сервере может требовать переменную `MAX_CA_PEM` (сертификат Минцифры) — это не настраивается в UI.
