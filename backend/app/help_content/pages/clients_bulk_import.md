# Массовое добавление клиентов

Пакетная загрузка клиентов из JSON (суперадмин).

## Что делать здесь

- Вставить массив клиентов в поле и нажать «Загрузить»
- Проверить, кого создали, кого пропустили как дубль и где ошибка

## Важно

- Визиты не создаются.
- Телефон нормализуется как в карточке; дубль номера (в базе или выше в файле) — строка пропускается.
- Без телефона клиент создаётся, если есть другой контакт **или** `contact_client_id` (контактное лицо уже существующего клиента) и при желании `contact_relation`.
- Дубли по имени не проверяются.
