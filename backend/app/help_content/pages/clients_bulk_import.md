# Массовое добавление клиентов

Пакетная загрузка клиентов из JSON (суперадмин).

## Что делать здесь

- Вставить массив клиентов в поле и нажать «Загрузить»
- Проверить, кого создали, кого пропустили как дубль и где ошибка

## Важно

- Визиты не создаются
- Телефон, который уже есть в базе или выше в файле, не создаёт второго клиента
