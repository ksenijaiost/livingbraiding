# Клиенты

Список карточек клиентов студии: поиск, фильтр по статусу, переход в карточку, создание нового клиента (для админов).

## Что делать здесь

- Найти клиента по имени или контакту
- Отфильтровать по статусу и отметкам (интерес к обучению, ученица, модель, не присылать акции)
- Открыть карточку — история, записи, визиты, последние сообщения
- Перейти в «Статистика» или в «Уведомления и рассылки»
- Создать нового клиента (если есть кнопка); суперадмин — ещё массовое добавление из JSON

## Важно

- Не дублируйте клиента: сначала поиск по телефону / мессенджеру.
- Статус в списке считается по неотменённым визитам и броням; «Заблокированы» — только при ручном ЧС в карточке.
- Значки у имени: 🚫 акции, 🎓 обучение, 📘 ученица, ✦ модель, 📝 активная бронь.
- Черновик (не подтверждён) ждёт админа — в списке помечен отдельно.
- Суперадмин может выгрузить весь список в CSV (вся база, не только результаты поиска).
