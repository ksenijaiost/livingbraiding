# Клиенты

Список карточек клиентов студии: поиск, переход в карточку, создание нового клиента (для админов).

## Что делать здесь

- Найти клиента по имени или контакту
- Открыть карточку — история, записи, визиты
- Создать нового клиента (если есть кнопка «Новый клиент»)

## Важно

- Не дублируйте клиента: сначала поиск по телефону / мессенджеру.
- Суперадмин может выгрузить весь список в CSV.
