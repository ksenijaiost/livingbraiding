# Возвращаемость клиентов

Сравнение клиентов периода посещения с повторными визитами в периоде возврата. Можно выбрать закрытый период ЗП или произвольные даты; при необходимости — фильтр по сотруднику.

## Что делать здесь

- Задать период посещения и период возврата
- При необходимости сузить отчёт по мастеру
- Посмотреть доли вернувшихся (новые / постоянные)
- Открыть список потерянных клиентов

## Важно

- Учитываются только неотменённые визиты.
- «Новые» — первый визит пришёлся на период посещения.
- По мастеру «вернулись» = снова были у этого сотрудника в периоде возврата.
