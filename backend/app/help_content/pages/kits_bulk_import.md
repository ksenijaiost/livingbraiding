# Массовый импорт комплектов

Пакетная загрузка комплектов (для старшего админа / суперадмина).

## Что делать здесь

- Подготовить файл по формату экрана
- Загрузить и проверить результат

## Важно

- Импорт может создать много записей сразу — сначала проверьте на малом файле
