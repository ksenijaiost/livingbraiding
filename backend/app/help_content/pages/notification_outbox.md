# Очередь уведомлений

Журнал последних 50 сообщений outbox (VK, Max, Telegram): сотрудникам (брони, напоминания, назначения) и клиентам (перед записью, после визита, ответы бота).

## Что делать здесь

- Проверить статус отправки (ожидает / отправка / отправлено / ошибка)
- Открыть связанную бронь по ссылке (если есть)
- Для записей со статусом «ошибка» — нажать «Повторить»

## Важно

- Автоповтор делает фоновый воркер; ручной повтор — для сбоев доставки.
- Сотруднику сообщение ставится только в канал, у которого этот тип отмечен.
- Назначение на событие уходит при создании, не при последующем редактировании.
- Что ушло клиентке по конкретной брони (в т.ч. по смене статуса) — в карточке брони, блок «Уведомления клиенту».
