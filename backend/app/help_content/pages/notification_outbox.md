# Очередь уведомлений

Журнал последних 50 сообщений outbox (VK / Telegram): брони (создание / изменение / отмена / напоминание) и назначения на событие при создании визита, продажи, работы, консультации, плана или почасовой.

## Что делать здесь

- Проверить статус отправки (ожидает / отправка / отправлено / ошибка)
- Открыть связанную бронь по ссылке (если есть)
- Для записей со статусом «ошибка» — нажать «Повторить»

## Важно

- Автоповтор делает фоновый воркер; ручной повтор — для сбоев доставки.
- Сообщения ставятся только сотрудникам с включёнными уведомлениями и подключённым каналом.
- Событие «назначение на событие» уходит при **создании**, не при последующем редактировании.
