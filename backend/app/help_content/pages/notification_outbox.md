# Очередь уведомлений

Журнал последних 50 сообщений outbox (VK / Telegram): создание, изменение, отмена брони и напоминания о записи.

## Что делать здесь

- Проверить статус отправки (ожидает / отправка / отправлено / ошибка)
- Открыть связанную бронь по ссылке
- Для записей со статусом «ошибка» — нажать «Повторить»

## Важно

- Автоповтор делает фоновый воркер; ручной повтор — для сбоев доставки.
- Сообщения ставятся только мастерам брони с включёнными уведомлениями и подключённым каналом.
