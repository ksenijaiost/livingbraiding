# Калькулятор товаров

Калькулятор для оценки/подбора товарных позиций.

## Что делать здесь

- Задать параметры расчёта
- Скопировать/использовать результат по смыслу экрана

## Важно

- Результат калькулятора сам по себе не списывает склад
