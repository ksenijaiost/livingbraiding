# SQL

Консоль SQL для диагностики и точечных фиксов: чтение (`SELECT` / `WITH` / `EXPLAIN`) и `UPDATE` строк с обязательным `WHERE`.

## Что делать здесь

- Выполнить допустимый запрос (чтение — без галочки подтверждения)
- Для `UPDATE` — отметить подтверждение записи и указать условие `WHERE`
- Проверить результат (для SELECT — первые 200 строк; для UPDATE — число затронутых)

## Важно

- `INSERT` / `DELETE` / DDL запрещены.
- `UPDATE` без `WHERE` запрещён — легко затронуть всю таблицу.
- Только разрешённые сценарии; опасные операции — по регламенту продукта.
