# Визиты

Журнал проведённых визитов. Можно сузить до «моих», показать отменённые, найти визит по номеру.

## Что делать здесь

- Открыть визит для просмотра / правки (если период и окно редактирования позволяют)
- Переключить «все / мои» и учёт отменённых
- Найти визит по ID в поиске

## Важно

- Новый визит мастер обычно создаёт из «Новый визит» или из брони/записи, а не из этого списка.
- В закрытом расчётном периоде правки ограничены.
