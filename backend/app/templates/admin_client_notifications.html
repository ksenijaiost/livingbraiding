Переменные шаблона (только «Перед записью»)

  • {{ "{{date}}" }} — дата ДД.ММ.ГГГГ
  • {{ "{{time}}" }} — время ЧЧ:ММ
  • {{ "{{datetime}}" }} — ДД.ММ.ГГГГ ЧЧ:ММ
  • {{ "{{date_text}}" }} — дата словами, напр. 16 сентября
  • {{ "{{weekday}}" }} — день недели, напр. среда
  • {{ "{{name}}" }} — имя клиента
  • {{ "{{services}}" }} — услуги с новой строки и маркером
  • {{ "{{masters}}" }} — мастера через запятую

Неизвестные {{ "{{…}}" }} остаются в тексте без изменений. Время — по часовому поясу студии, начало брони = bookings.planned_date.
