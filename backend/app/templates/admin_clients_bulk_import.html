Массовое добавление клиентов (JSON)

Доступно только суперадминистратору. Корень JSON — массив объектов; допускается только строгий JSON (без // и хвостовых запятых). Лимиты: до {{ (max_bytes // 1024)|int }} KB текста, не более {{ max_clients }} клиентов за один запрос.

Телефон нормализуется так же, как в карточке клиента. Если такой телефон уже есть в базе или выше в этом файле, строка не создаётся. Без телефона клиент создаётся, дубли по имени не проверяются. Визиты не создаются.
