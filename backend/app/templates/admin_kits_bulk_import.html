Массовая загрузка комплектов (JSON)

Доступно только суперадминистратору. Корень JSON — массив объектов; допускается только строгий JSON (без // и хвостовых запятых). Лимиты: до {{ (max_bytes // 1024)|int }} KB текста, не более {{ max_kits }} комплектов за один запрос.

Если артикул уже занят в базе или в этом же файле, к сохранённому артикулу добавляется суффикс ❗повтор, при необходимости ❗повтор2 и далее (до 80 символов).

Поля JSON и подписи в карточке комплекта:

Обязательность и автоподстановки — в колонке «Обязательность». Для необязательных полей там стоит «—».

Поле JSON Обязательность Как в UI
skuДаАртикул (непустая строка)
titleДаНазвание
blank_type_de
blank_type_se		ДаТип заготовок — D.E. и/или S.E. (хотя бы одно true)
cost_totalДаСебестоимость (всего), ₽ — число > 0
pieces_initialДа / —Количество заготовок при создании. Обязательно, если нет composition. Если composition задан и поле не указано — авто: сумма количеств по составу.
stock_price_total—Цена на складе (всего), ₽. Если не указано и задан composition — авто по прайсу «Заказ» → «Заготовки поштучно» (нужны цены в каталоге по всем ключам состава); иначе укажите вручную число > 0.
composition—Состав → composition_json. Объект "КЛЮЧ": qty или массив [{"key","qty"},…]. Без состава нельзя посчитать сумму заготовок и цену по ключам автоматически.
blank_stock—Остатки по kit_key (объект "КЛЮЧ": остаток). Если composition задан, а blank_stock нет или пустой — авто: те же количества, что в составе. Иначе укажите явно, чтобы задать другой фактический остаток по видам.
discount_percent—Скидка (всего), % (по умолчанию 0; не выше допустимой маржи к цене и себестоимости)
blanks_condition—Состояние заготовок — NEW / USED / MIXED (по умолчанию NEW)
weight_grams—Вес, г
length_cm—Длина, см
materials_text—Материалы
color_text—Цвет
description—Описание комплекта
notes—Примечание
author_external—Извне (не сотрудник студии)
author_user_ids—Мастера — массив id пользователей

Ключи заготовок (kit_key)

Ключи в composition и blank_stock — это kit_key из каталога «Заказ» → «Заготовки поштучно» (активная позиция с таким ключом в meta_json). Ниже эталонный список из кода приложения; в вашей базе набор может отличаться — ориентируйтесь на каталог.

Для б/у в каталоге могут быть отдельные ключи, например SE_BRAID_USED и DE_DREAD_USED.
