Массовая загрузка комплектов (JSON)

Доступно только суперадминистратору. Корень JSON — массив объектов; допускается только строгий JSON (без // и хвостовых запятых). Лимиты: до {{ (max_bytes // 1024)|int }} KB текста, не более {{ max_kits }} комплектов за один запрос.

Если артикул уже занят в базе или в этом же файле, к сохранённому артикулу добавляется суффикс ❗повтор, при необходимости ❗повтор2 и далее (до 80 символов).

Поля JSON и подписи в карточке комплекта:

Обязательность и автоподстановки — в колонке «Обязательность». Для необязательных полей там стоит «—».

Поле JSON Обязательность Как в UI
skuДаАртикул (непустая строка)
titleДаНазвание
blank_type_de
blank_type_se		Да / —Тип заготовок — D.E. и/или S.E. (хотя бы одно true). Если оба не указаны или оба false, а задан непустой composition — авто по префиксам ключей: DE_* / SE_* (или устаревшие ключи DE / SE).
cost_totalДаСебестоимость (всего), ₽ — число > 0
pieces_initialДа / —Количество заготовок при создании. Обязательно, если нет composition. Если composition задан и поле не указано — авто: сумма количеств по составу.
stock_price_total—Цена на складе (всего), ₽. Если не указано и задан composition — авто по прайсу «Заказ» → «Заготовки поштучно» (нужны цены в каталоге по всем ключам состава); иначе укажите вручную число > 0.
composition—Состав v2 → composition_json. Количество: "qty": N или "by_staff": {"id": qty}. Для всех строк USED без своего used_price_pct — общий % из used_discount_percent (не путать с discount_percent!). blanks_condition считается из condition строк.
used_discount_percent—Скидка % от прайса «Заготовки поштучно» только для строк USED в составе, если у строки нет used_price_pct. Пример: 2 NEW + 4 USED и скидка 50% на б/у → "used_discount_percent": 50, в USED-строках used_price_pct не нужен.
is_active—Актуален (по умолчанию true; false — в конце списка комплектов, не в выборе «из наличия»)
blank_stock—Остатки по kit_key (объект "КЛЮЧ": остаток). Если composition задан, а blank_stock нет или пустой — авто: те же количества, что в составе. Иначе укажите явно, чтобы задать другой фактический остаток по видам.
discount_percent—Скидка на весь комплект при продаже со склада, % (по умолчанию 0; не на отдельные виды в составе — для USED в составе см. used_discount_percent)
blanks_condition—Устарело при v2-составе: вычисляется из condition строк. Без состава — NEW / USED / MIXED (по умолчанию NEW).
weight_grams—Вес, г
length_cm—Длина, см
materials_text—Материалы
color_text—Цвет
description—Описание комплекта
notes—Примечание
author_external—Извне (не сотрудник студии)
author_user_ids—Мастера — массив id пользователей

Ключи заготовок (kit_key)

В прайсе колонка «Наименование» — это поле name в базе (человекочитаемая подпись). В JSON для composition и blank_stock нужны ключи из meta_json.kit_key активных строк «Заказ» → «Заготовки поштучно» (задаются в каталоге рядом с позицией). Строка без kit_key или без цены не участвует в автосчёте цены склада и не попадает в эту таблицу.
